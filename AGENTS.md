# Layout rules
- Use the shared compact header menu below the wide-desktop breakpoint so the logo and navigation never compete for tablet width.
- Keep tax-year and province controls in wrapping groups stacked below the wide-desktop breakpoint so every option stays visible.
- Use two footer columns on tablets and four only on wide screens so contact details remain within the page.
- Keep Super Visa rate tables unchanged when redesigning the comparison; show Standard and Enhanced separately and GMS as a single plan so unlike products are not presented as identical.
- Keep Destination Canada rate lookup in its own data module, with unavailable cells returning no quote and monthly terms requiring broker confirmation because the supplied schedule gives no installment formula.
